Why forgetting is the price of remembering cheaply.

Every Transformer keeps every word. That’s why it never forgets — and why long chats get slow and expensive. Recurrent models throw away the filing cabinet and keep one whiteboard. Cheap forever, but things get erased. Play with both below, break the whiteboard, then see where a real brain-inspired machine — Dragon Hatchling (BDH) — made the same bet.

FALSIFIABLE CLAIM · TRY TO BREAK IT
KV-cache grows O(n) and stays exact. Fixed recurrent state stays O(1) but silently forgets when writes collide. If you can make recurrent stay perfect at n=500 with N=16, the claim is wrong.

BDH module · not an appendix

You just felt BDH’s design decision in your fingers.

System: Dragon Hatchling (BDH), Pathway’s Post-Transformer family. Not a Mamba-style SSM — BDH-GPU is a separate GPU-friendly rewrite from ReLU low-rank maps + linear attention. What changes is synaptic state, not a token drawer: attention becomes memory written into synapses as the model reads (Hebbian writes).

ρt−1,l = Στ<t v*τ,l−1 xτ,lT Ut−τ — BDH-GPU attention state, Eq.5: fixed-shape matrix, additive updates, O(1) in length

Same bargain as your whiteboard, now with learned keys, decay U, ~5% sparse non-negative activity. See Kosowski et al. §3.2 Eqs.4–5; Hebbian lens Eqs.6–8; official toy BDH code App.E.

Precomputed · vendor-reported: 134M BDH hits 95% at 32K → 82% at 128K on BABILong QA1–QA5 (pathway.com). Holds long, sags under load — your toy’s curve at real scale. Pending contamination / independent / leaderboard review. Benchmark ≠ deployment.
Sibling BDH-CQ: 150M, 29.5% pass@2 on ARC-AGI-1 @ ~$0.0007/task (arXiv:2608.09888). Latent recurrence, no chain-of-thought tokens — a cost-accuracy Pareto point, not raw SOTA. Self-reported, checkpoint unreleased.

Don’t leave with the wrong lesson: forgetting here is silent (no “I forgot” light). And session memory ≠ durable learning — moving useful fast state into slow weights (fast-to-slow) is still open. Never file BDH under “SSM”.
