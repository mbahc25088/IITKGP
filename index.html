KV-Cache Grows. Recurrent State Forgets.

One falsifiable claim: A Transformer KV-cache allocates a new slot per token — memory grows O(n) and retrieval stays exact. A fixed-size recurrent state stays O(1) but silently forgets through interference when writes collide.

3. BDH module — where this trade-off lives in a real architecture

Which system: Dragon Hatchling (BDH), Pathway's Post-Transformer family. Not an SSM in the Mamba sense — BDH-GPU is a separate GPU-friendly formulation built from ReLU low-rank transforms with linear attention (per the approved-topic note).

What's changing in BDH is synaptic state, not a token-indexed cache. Conceptually, attention becomes synaptic memory through Hebbian writes as the model reads. One reference equation (BDH-GPU attention state, Eq. 5 in the paper):

ρt−1,l = Στ<t v*τ,l−1 xτ,lT Ut−τ

A fixed-shape matrix ρ accumulates past associations additively (O(1) in length) — same design choice your toy illustrated, now with learned keys/values, decay U, and sparse non-negative activity. See Kosowski et al. §3.2, Eqs. 4–5; Hebbian view in Eqs. 6–8 and the official toy BDH implementation.

Clearly-labeled precomputed evidence (developer-reported, not independent): on BABILong QA1–QA5, a 134M-parameter BDH model reaches 95% at 32K tokens, 82% at 128K (pathway.com homepage). Same pattern as your toy: holds long, then degrades under load. Label: vendor benchmark, pending contamination checks / independent validation / leaderboard review.

Sibling system BDH-CQ (same family, different benchmark): 150M params, 29.5% pass@2 on ARC-AGI-1 at ~$0.0007/task — a cost-accuracy Pareto point achieved by recurrent latent reasoning without verbal chain-of-thought (arXiv:2608.09888). Shows the O(1)-state family trading raw accuracy for intelligence-per-dollar.

Limitation / misconception: fixed-state ≠ free lunch; interference is silent (no "I forgot" flag). Within-session memory ≠ durable cross-session learning — consolidating useful fast state into slow weights remains open (fast-to-slow transfer). Do not equate BDH with Mamba-style SSM.

  3. Cui. A Hippocampus for Linear Attention: An Exact Memory for What the Recurrent State Forgets. arXiv:2607.02303 (2 Jul 2026). Independent statement of our claim: fixed-size recurrent state = O(1) but lossy; competing key–value writes overwrite earlier facts. arxiv
  4. Gu & Dao. Mamba: Linear-Time Sequence Modeling with Selective State Spaces. 2024 — representative SSM baseline for the summary comparison table; BDH cites as related work but is architecturally distinct.
